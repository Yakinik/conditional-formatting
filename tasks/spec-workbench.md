# 条件付き書式ワークベンチ v2 実装契約

## 目的

表を主役にし、同一画面の右サイドバーで条件付き書式を作成・確認する。
すべての条件カテゴリを AND / OR / NOT で組み合わせ、選択範囲と実データへ即時反映する。

## 技術・構造

- Preact + TypeScript + Vite
- アプリ状態は `@preact/signals`
- パッケージ管理は pnpm
- Feature-Sliced Design v2.1 の最小構成: `app / pages / shared`
- 単一画面固有の UI・モデル・取り込み処理は `pages/workbench` に置く
- `features / entities / widgets` は実利用の再利用先がないため作らない
- 静的な GitHub Pages 配信を維持する

## 正規データモデル

```text
Workbook
└─ Sheet[]
   ├─ Cell[][]
   └─ ordered Rule[]
      ├─ appliesTo
      ├─ recursive condition group (AND / OR / NOT)
      ├─ format
      ├─ enabled
      └─ stopIfTrue
```

## 新規機能

- 複数シートとシートタブ
- 範囲選択と「選択範囲を適用」
- 優先順位付き複数ルール
- 再帰的な条件グループ
- 選択ルールだけを確認する「ルールレンズ」
- ファイル選択・ドロップ: XLSX / CSV / TSV
- 表形式テキストの貼り付け
- データ処理はブラウザ内で完結

## 境界

- XLSX 内の値、シート名、日付・数値・真偽値を取り込む
- XLSX 内に既存する条件付き書式ルールの解析・再現は対象外
- 一般的なスプレッドシート数式計算、XLSX 書き出し、完全なセル編集は対象外
- 表示・取り込みは安全な上限を設け、超過時は明示する
