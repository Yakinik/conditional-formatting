# 条件付き書式ジェネレータ

Google スプレッドシート / Excel の **条件付き書式** でよく使うパターンを選ぶだけで、
そのまま貼り付けられる **カスタム数式** と **設定手順** を作成する静的サイトです。

- 依存ライブラリ・ビルド不要の Vanilla JS(HTML / CSS / JS の 3 ファイルのみ)
- 適用範囲を変えると数式のセル参照も自動で追従
- Google スプレッドシートと Excel で、数式と手順を切り替えて表示
- 設定後の見た目をスプレッドシート風のプレビューで確認できます

公開 URL: <https://yakinik.github.io/conditional-formatting/>

## 使い方

1. **やりたいことを選ぶ** — パターンのカードをクリックします。
2. **条件と色を設定する** — 適用範囲・キーワード・しきい値などを入力し、色を選びます。
3. **数式をコピーして貼り付ける** — 表示された手順どおりに条件付き書式を設定します。

ヘッダー右上のトグルで、対象アプリ(Google スプレッドシート / Excel)を切り替えられます。

## 対応パターン(13 種類)

### 文字・キーワード

| パターン | 内容 |
|---|---|
| キーワードに反応して色を付ける | 部分一致 / 完全一致 / 前方一致 / 後方一致 で判定 |
| 複数のキーワードのいずれかに反応 | 複数の語のどれかを含むセルに色を付ける |

### 行全体の色付け

| パターン | 内容 |
|---|---|
| 特定の列の値で行全体を色付け | ステータス列が「完了」の行をまとめて色付け |
| チェックボックスがオンの行を色付け | チェック済みの行全体を色付け |

### 数値

| パターン | 内容 |
|---|---|
| 数値がしきい値を超えたら色付け | 以上 / より大きい / 以下 / より小さい / 等しい / 等しくない |
| 数値が範囲内なら色付け | 下限〜上限の範囲に入る数値を色付け |

### 日付・期限

| パターン | 内容 |
|---|---|
| 期限切れの日付を色付け | 今日より前(または今日を含む)の日付を色付け |
| 期限が近い日付を色付け | 今日から N 日以内の日付を色付け |
| 土日の日付を色付け | 土日 / 土曜のみ / 日曜のみ を色付け |

### その他の定番

| パターン | 内容 |
|---|---|
| 空白セル(未入力)を色付け | 空白 / 空白でないセルを色付け |
| 重複しているデータを色付け | 重複するすべて / 2 個目以降だけを色付け |
| 1 行おきに色を付ける(縞模様) | 偶数行 / 奇数行のゼブラ模様 |
| 別のリストにある値を色付け | 別範囲・別シートのリストと一致する値を色付け |

## ローカルでの確認方法

`index.html` をブラウザで直接開くだけでも動作します。
ローカルサーバで確認する場合は次のとおりです。

```sh
python3 -m http.server 8000
```

起動後、<http://localhost:8000/> を開きます。

## ファイル構成

```
index.html   マークアップ(要素の ID / クラス契約)
style.css    スタイル(方眼紙 × 帳簿の意匠)
app.js       パターン定義・数式生成・描画
```

## ブランチ構成

- `main`: README などのプロジェクト情報(デフォルトブランチ)
- `develop`: ソースコードと作業文書
- `gh-pages`: GitHub Pages で配信するファイル
