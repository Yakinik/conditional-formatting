# 条件付き書式ジェネレータ

Google スプレッドシート / Excel の **条件付き書式** でよく使うパターンを選ぶだけで、
そのまま貼り付けられる **カスタム数式** と **設定手順** を作成する静的サイトです。

- 依存ライブラリ・ビルド不要の Vanilla JS(HTML / CSS / JS の 3 ファイルのみ)
- 適用範囲を変えると数式のセル参照も自動で追従
- Google スプレッドシートと Excel で、数式と手順を切り替えて表示
- 設定後の見た目をスプレッドシート風のプレビューで確認できます

公開 URL: <https://yakinik.github.io/conditional-formatting/>
